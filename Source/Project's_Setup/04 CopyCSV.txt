/*

Why do I have to import the CSVs manually?

Because you are using pgAdmin Query Tool, and your CSV files are stored on your Windows computer.

Your COPY query tells PostgreSQL:

> Server, go and read this file.

But the PostgreSQL server doesn't have permission to access your Desktop folder.

The \copy command would solve this because your computer reads the file, but \copy only works in psql/SQL Shell, not in pgAdmin Query Tool.

So in your current setup:


CSV on your PC
      ↓
pgAdmin Import/Export
      ↓
PostgreSQL table


You have to use the Import/Export Data option in pgAdmin because it lets pgAdmin access your local file and load it into PostgreSQL.

you are not manually entering the data. You only manually select each CSV file; pgAdmin imports all the rows automatically.

*/
